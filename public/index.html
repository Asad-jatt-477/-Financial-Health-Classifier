The problem

Public financial statements contain everything needed to judge a company's health — but they arrive as thousands of raw, inconsistent regulatory filings, not a clean table. This project turns 10 quarters of SEC filings (~36 million raw facts) into one focused question:

Will this company be financially At-Risk or Healthy next quarter, using only what's in its current filing?

How the target is defined

A company-quarter is labelled Healthy if current_ratio ≥ 1 and NetIncomeLoss > 0 — otherwise At-Risk. The prediction target is this label, shifted one quarter forward, so the model must genuinely forecast rather than describe the present.
